# StaggeredMenu (React Bits, JS-CSS)

Source: https://reactbits.dev/r/StaggeredMenu-JS-CSS.json
Docs: https://reactbits.dev/components/staggered-menu
Dependency from registry: gsap@^3.13.0 (installed through npm).

The JSX and CSS were downloaded from the official registry. Local adaptations keep the original GSAP layer and text animations, translate labels into Spanish, replace the sample logo with the Signum text wordmark, and add current-page state, Escape, keyboard focus containment, inert closed links, scroll locking and reduced-motion handling. JSDoc supplies prop types for Astro without changing the JS-CSS variant.

Header.astro supplies the real routes and professional social links. Final site styling lives in baseline.css. No example Twitter/GitHub accounts or logo placeholder are used.
